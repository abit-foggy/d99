d99 APT Repository

Debian packaging toolchain in C99. Fast, self-contained replacements and companions for dpkg, apt, and debian tools.

Quick Setup

Add this repository to your system APT sources:

# Add repository source
echo "deb [trusted=yes] https://abit-foggy.github.io/d99/repo/ stable main" | sudo tee /etc/apt/sources.list.d/d99.list

# Update package index and install d99
sudo apt update
sudo apt install d99

Or using flat repository format:

echo "deb [trusted=yes] https://abit-foggy.github.io/d99/repo/ ./" | sudo tee /etc/apt/sources.list.d/d99.list
sudo apt update
sudo apt install d99
